# Day 39 – Dashboard Design, Slicers and Drill-Through

## Objective
Learn to design interactive Power BI dashboards using charts, slicers, tables, and drill-through functionality.

## 1. Dashboard Visualizations

Practiced the following visualizations:

- Sales by Country – Clustered Column Chart
- Profit by Country – Bar Chart
- Sales by Product – Bar Chart
- Profit by Product – Column Chart
- Sales by Category – Column Chart
- Profit by Category – Bar Chart
- Sales vs Profit – Scatter Chart
- Transaction Details – Table

## 2. Slicers

Created slicers using:
- Country
- Category

Slicers allow users to filter dashboard data dynamically.

## 3. Edit Interactions

Used Edit Interactions to control how slicers and visuals affect other dashboard visuals.

Tested filtering behavior to ensure relevant charts and tables update when selections change.

## 4. Drill-Through

Created a separate Country Details report page.

**Drill-through configuration:**
- Added Country as the drill-through field.
- Created a country-level details table.
- Included Product, Total Sales, Total Profit, and Profit Margin KPI.

Tested drill-through by right-clicking a country in the Sales by Country chart and navigating to the Country Details page.

## 5. Dashboard Design Principles

- Use meaningful chart titles.
- Keep related visuals together.
- Maintain consistent formatting.
- Align charts and slicers.
- Avoid unnecessary visual clutter.
- Make important business metrics easy to understand.

## Key Learnings
- Creating interactive dashboards.
- Using slicers for dynamic filtering.
- Managing visual interactions.
- Implementing drill-through navigation.
- Designing report pages for business analysis.

## Conclusion
Interactive dashboards help users explore data, compare business performance, and investigate detailed information efficiently.
