# Day 30 — Power Query Conditional and Custom Columns

## Objective
Learn to create calculated and conditional columns in Power BI using Power Query Editor and basic M language.

## Concepts Practiced

### 1. Conditional Column
- Created `Profit Status` using the `Profit` column.
- Classified positive profit as `Profitable` and zero or negative profit as `Not Profitable`.

### 2. Custom Column
- Created `Sales Difference` using the formula:
  `[Gross Sales] - [Sales]`

### 3. Basic M Language
- Practiced `if ... then ... else` syntax.
- Created `Sales Category` based on a sales threshold.

### 4. AI-Assisted Formula Development
- Used an AI-assisted workflow to draft a multi-condition sales classification formula.
- Created `Sales Level` with `High`, `Medium`, and `Low` categories.
- Verified results against the defined thresholds.

## Validation
- Checked calculated values and category outputs.
- Checked column quality for errors.
- Applied changes and verified the existing report.

## Key Learning
Conditional columns classify data using business rules, while custom columns use expressions to calculate new values. AI can help draft formulas, but results must be independently checked.

## Tools Used
- Power BI Desktop
- Power Query Editor
- M language
- ChatGPT
- VS Code and GitHub
